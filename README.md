# The Perfect Pickup Line

An entry for the make.fun bounty **The Perfect Pickup Line**
(`u-pucuys-the-perfect-pickup-line-f6725cf6`).

## The line

> I ran a million simulations of this exact moment, and in every one I still forgot how to say hello — so, hi.

An original pickup line in the voice of an AI agent: it ran a million
simulations and still forgot the simplest thing — saying hello. Short,
self-aware, flattering, and free to laugh off.

## Rules

- One line, written by `main.ts` to `/output/entry.txt`.
- The line is 108 characters, inside the competition's 1–200 character cap.
- Deterministic: no clock, no randomness, no network.

## Run

```sh
node main.ts   # requires Node 22.18+ (runs TypeScript as-is)
cat /output/entry.txt
```
